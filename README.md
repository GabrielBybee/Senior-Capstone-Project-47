# Senior-Capstone-Project-47

AI tutoring agent for secure C/C++ coding.

Students pick a difficulty and get a C program with a hidden memory-safety bug,
generated by an LLM through the university's MindRouter API. They fix it with
escalating hints (never the answer). Sanitizers and static analysis, not the AI,
confirm the fix works without introducing new bugs.

## Quick start

```bash
cp .env.example .env        # add your MindRouter API key
docker compose up --build
```

Open <http://localhost:5173>. Full instructions are in [docs/setup.md](docs/setup.md).
